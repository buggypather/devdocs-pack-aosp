Security testing

In addition to general platform testing, Android offers the security-specific mechanisms described in this section to detect and harden your devices against vulnerabilities.

This section summarizes tools for security testing and debugging. It covers some tools for fuzzing, sanitizing, and preemptively mitigating exploits. For general debugging, see the debugging section.
