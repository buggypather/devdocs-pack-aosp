Local development

To set up a local Linux workstation for AAOS SDV development, follow Set up for AOSP development (9.0 or later) and make sure your host machine has:

  • 64-bit Ubuntu Linux
  • At least 64 GB of RAM and 400 GB of free disk space
  • KVM virtualization enabled on the CPU (grep -cw 'vmx\|svm' /proc/cpuinfo returns a non-zero count)
  • Cuttlefish host packages installed (see Get started with Cuttlefish)
