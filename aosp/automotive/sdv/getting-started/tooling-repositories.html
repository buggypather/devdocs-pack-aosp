Access GitHub repositories

Google provides the following GitHub repositories for SDV:

  • GitHub MCG repository: Source code for the Metrics Configuration Generator, a tool that simplifies authoring SDV telemetry configurations.

  • SDV Telemetry GitHub: Source code for Cloud Telemetry Simulation, a platform that provides a scalable, on-demand infrastructure to run vehicle telemetry simulations on Google Cloud.

Use standard GitHub commands to clone the repositories you want to use.
