Unbundled apps release notes

Unbundled apps are those not included in the Android Automotive OS (AAOS) system image (they're listed on this page). To learn how to integrate unbundled apps into vehicles, see the Integration guide.

  • Integrate AppCards
  • Automotive app host
  • Calendar
  • Car UI library
  • Companion device
  • Control Center reference app
  • Dialer
  • Media
  • Short Message Service (SMS)
  • Sensitive App Protection
Note: App Lock and Sensitive App Protection (SAP) refer to the same feature in this context.

Car-apps-release-20

Tag: ub-automotive-master-20251118

Car-apps-release-20 addresses these issues.

New features

Sensitive App Protection provides users with privacy options to protect sensitive apps in the car. For example, Chrome and WhatsApp. The program lets users lock apps behind a PIN even if they haven't set a profile lock. This PIN is independent from profile lock.

The Control Center reference application demonstrates user experiences you can add to your multi-user, multi-display (MUMD) environments. Some user journeys include:

  • View what others in the car are watching and listening to.
  • Share audio to car speakers.
  • Co-watch a video with other displays in the car.

Control Center aims to enhance the user experience in a vehicle configuration when one or more secondary displays accompany the driver display. For example, for a rear passenger.

We plan to add more documentation for Control Center.

Caution: Control Center is a reference application only. Google does not intend for this app to be shipped to production. OEMs should build their own app and not ship Control Center as-is to production.

Issues addressed

Media:

  • Updated the MediaBlockingActivity layout to be compatible with RROs.
  • Enabled an overlay of Audio Settings action.

Dialer:

  • Made the ongoing call layout and nested layouts compatible with RROs.

Car Library:

Other issues:

  • Updated the Maven URL to use Google's mirror of mavenCentral
  • Updated to Gradle 9.1.0.
  • Corrected the IMethod for using the Android Gradle plugin in a Gradle build plugin.
  • Updated Robolectric to version 4.16.
