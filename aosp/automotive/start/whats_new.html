What's new

This page provides a list of all new content and significant revisions for the Android Automotive OS.

June 2026

(June 23) Added Software-Defined Vehicle (SDV) to describe how Android Automotive is expanding beyond infotainment to power other vehicle domains and support centralized, updatable software architectures.

December 2025

(December 3) Added Control Center reference app to help you add multi-display, multi-user use cases to your apps.

October 2025

(October 28) Added Enable multi-client cameras to describe how you can enable multiple clients to simultaneously access a camera.

(October 22) See Advanced windowing with Scalable UI to build dynamic and multi-panel user experiences in cars.

September 2025

(September 24) Added Migrate to Camera2 to describe how to migrate to Camera2 from the Extended View System (EVS).

June 2025

(June 11)

  • Added a new entry to describe Car-apps-release-17.
  • Added new pages to describe how to Integrate AppCards.
  • Added a new page to describe the new features provided in Android Automotive 25Q2.

April 2025

(April 11) Added a new entry to describe Car-apps-release-16.

(April 3) Added a new page to describe Automotive Window Layering.

March 2025

(March 21) Added a new page to describe how to Integrate Dashcam.

(March 4) Added a new page to describe the Android Automotive 25Q1 release.

February 2025

(February 14) Added a new page to describe ⇉Android Automotive 25Q1 release details.

(February 13) Added a new page to describe how to Throttle and suppress notifications.

December 2024

(December 18) Added a new page to describe the features in Android Automotive 2024Q4.

(December 12) Added a new page to describe how to Integrate deep links to Media apps.
