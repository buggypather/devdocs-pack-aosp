Android Automotive 13 QPR3 release details

This page summarizes new features provided in Android Automotive 13 QPR3.

Features

This release provides the ability to inject InputEvent into the TaskView hosted activity.

Compliance

Android compliance tests were executed on the internal reference hardware. The Compatibility Test Suite (CTS), Security Test Suite (STS), Vendor Test Suite (VTS), and CTS-on-GSI test suites were run on this build.
