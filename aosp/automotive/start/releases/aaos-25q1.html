Android Automotive 25Q1

This release addresses issues only.

API level: 35

Features

No new features are included in this release.

Compliance

Android Compliance was executed on internal reference hardware. Test suites run for this release include CTS, CTS-V, ATS, ATS-V, STS, VTS, and CTS -on-GSI.

We don't recommend this 25Q1 release to be production ready with respect to compliance. Any test failures identified in this release will be fixed in an upcoming release.

For Android 15, Android Automotive recommends the Android Automotive 24Q4 release for compliance.
