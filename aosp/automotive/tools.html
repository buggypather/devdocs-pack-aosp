Testing tools and infrastructure

To maximize efficiency and ensure compliance, we provide a scalable infrastructure and robust set of testing tools:

  • System performance tools. Identify and measure performance metrics.

  • User interface frameworks. To test the user interface.

  • Network simulation. Simulate different network conditions on in a scalable and low-maintenance way.

  • Complete Automotive Tests in a Box (CATBox). An open source package that provides the frameworks and tools required to streamline and execute automotive tests with minimal configuration.

  • Enable fuzzers. Use fuzz tests to find security-related bugs.

  • Spectatio. Another open source package, use the Spectatio test framework to test the Android Automotive on real and virtual devices.

  • Torq. A command-line tool designed to streamline and standardize OS performance profiling across Android Automotive devices.
