Set up the testing equipment

Connect and configure the testing equipment. The hardware required to test the device under test (DUT) is:

  • 3-axis accelerometer (35C-10)
  • 3-axis accelerometer cable
  • Vibration isolation platform
  • 3M CF-40EG with 25.4 mm thickness foam
  • Data acquisition card (sound card)
  • CCLD signal conditioner
  • Beeswax: YJ-0216
