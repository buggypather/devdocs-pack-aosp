Quick Settings tiles categorization

Android 16 QPR2 includes Quick settings tiles categories (added in Beta 1), which are described in Create custom Quick Settings tiles for your app. These categories sort tiles in Quick Settings Edit mode so users can find tiles faster.

See Categorize your tile for developer info.

The TileService class is qualified with metadata from constants including META_DATA_TILE_CATEGORY, CATEGORY_CONNECTIVITY, and CATEGORY_ACCESSIBILITY.

Implementation

META_DATA_TILE_CATEGORY is an optional constant that partners can fetch from the metadata TileService. Pixel devices use this to sort tiles in the Quick Settings edit mode.
