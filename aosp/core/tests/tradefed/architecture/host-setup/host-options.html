Tradefed host options

Host options in Tradefed (TF) refer to options that are applied at the host level (one TF instance), and affect the behavior of the harness itself. These options usually don't affect tests themselves but rather support operations the harness provides.

Host options define a range of options that allows customization of TF behavior, such as:

  • How many devices can be flashed concurrently. This is useful for physical hosts with limited resources.
  • The directory files should be downloaded to. If the default temporary folder isn't the right place for any reason, it's possible to change it.
