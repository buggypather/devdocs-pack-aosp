Compatibility Test Suite downloads

Thank you for your interest in Android Compatibility! The links on this page give you access to key documents and information about the Compatibility Test Suite (CTS) program. When CTS is updated, new versions are added to this page. CTS versions are denoted by R number in the link name.

Important: The unzipped downloaded tests folder must not be renamed. For example, android-cts inside the android-cts-\*.zip must keep the same name to work properly.

CTS media files

The following media files are required for the CTS media stress tests:

  • CTS Media 1.5
  • CTS Media 1.4

Android 17

Android 17 (API level 37) is the release of the development milestone codenamed C. Sync the source code for the following tests using the android-cts-17.0_r3 tag in the open source tree:

  • Compatibility Test Suite (Chunked-CTS) 17 R3 - ARM
  • Compatibility Test Suite (Chunked-CTS) 17 R3 - x86
  • Compatibility Test Suite (CTS) 17 R3 - ARM
  • Compatibility Test Suite (CTS) 17 R3 - x86
  • CTS Verifier 17 R3 - ARM
  • CTS Verifier 17 R3 - x86

Android 2.1 (API level 5) is the release of the development milestone codenamed Eclair. Source code for Android 2.1 is found in the eclair branch in the open source tree. For technical reasons, there is no compatibility program for Android 2.0 or 2.0.1. New devices must use Android 2.1.

  • Compatibility Test Suite (CTS) 2.1 R5

Android 1.6

Android 1.6 (API level 4, NDK 2) was the release of the development milestone codenamed Donut. Android 1.6 was obsoleted by Android 2.1. Source code for Android 1.6 is found in the donut branch in the open source tree:

  • Compatibility Test Suite (CTS) 1.6 R1

Lower Android versions

There is no Compatibility Program for lower versions of Android, such as Android 1.5 (codenamed Cupcake). New devices intended to be Android compatible must ship with Android 1.6 or later.
